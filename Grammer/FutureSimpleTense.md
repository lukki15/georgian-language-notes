# Future Simple Tense

## V-System Verbs

### Ending in –ობ Without Preverbs

Take the 1st person singular form of the verb.
Add **ი** after the person marker **ვ**, drop the ending **–ობ**, and add **–ებ**.
Conjugate following the chart below.

| Infinitive                  | Present Simple 1st person singular | Future Simple Tense |
| --------------------------- | ---------------------------------- | ------------------- |
| To have a dinner (სადილობა) | ვსადილობ                           | ვ-ი-სადილ-ებ        |

|                        | To have a dinner (სადილობა) |
| ---------------------- | --------------------------- |
| მე ვი ––––––––– ებ     | მე **ვი**სადილ**ებ**        |
| შენ ი ––––––––– ებ     | შენ **ი**სადილ**ებ**        |
| ის ი ––––––––– ებს     | ის **ი**სადილ**ებს**        |
| ჩვენ ვი ––––––––– ებთ  | ჩვენ **ვი**სადილ**ებთ**     |
| თქვენ ი ––––––––– ებთ  | თქვენ **ი**სადილ**ებთ**     |
| ისინი ი ––––––––– ებენ | ისინი **ი**სადილ**ებენ**    |

Some verbs take ვ before endings:

| Infinitive        | Present Simple 1st person singular | Future Simple Tense |
| ----------------- | ---------------------------------- | ------------------- |
| To work (მუშაობა) | ვმუშაობ                            | ვ-ი-მუშა-ვებ        |

|                         | To work (მუშაობა)        |
| ----------------------- | ------------------------ |
| მე ვი ––––––––– ვებ     | მე **ვი**მუშა**ვებ**     |
| შენ ი ––––––––– ვებ     | შენ **ი**მუშა**ვებ**     |
| ის ი ––––––––– ვებს     | ის **ი**მუშა**ვებს**     |
| ჩვენ ვი ––––––––– ვებთ  | ჩვენ **ვი**მუშა**ვებთ**  |
| თქვენ ი ––––––––– ვებთ  | თქვენ **ი**მუშა**ვებთ**  |
| ისინი ი ––––––––– ვებენ | ისინი **ი**მუშა**ვებენ** |

#### Exceptions:

| Translation | Infinitive | Present  | Future Simple |
| ----------- | ---------- | -------- | ------------- |
| To buy      | \*ყიდვა    | ვყიდულობ | ვიყიდი        |
| To learn    | \*სწავლა   | ვსწავლობ | ვისწავლი      |

| Irregular Verb | To go (წასვლა) |
| -------------- | -------------- |
| მე წავალ       | ჩვენ წავალთ    |
| შენ წახვალ     | თქვენ წახვალთ  |
| ის წავა        | ისინი წავლენ   |

### with preverb

If a verb has a preverb in the infinitive,
take the first person singular form of the verb,
add the preverb from the infinitive, and conjugate following the chart.

| Infinitive       | Present Simple 1st person singular | Future Simple Tense |
| ---------------- | ---------------------------------- | ------------------- |
| To do - გაკეთება | ვაკეთებ                            | გა + ვაკეთებ        |

| Future Simple Tense             | To do - გაკეთება |
| ------------------------------- | ---------------- |
| მე preverb + ვ–––––––––         | **გა**ვაკეთებ    |
| შენ preverb + –––––––––         | **გა**აკეთებ     |
| ის preverb + –––––––––ს/ა       | **გა**ვაკეთებ    |
| ჩვენ preverb + ვ–––––––––თ      | **გა**ვაკეთებთ   |
| თქვენ preverb + –––––––––თ      | **გა**აკეთებთ    |
| ისინი preverb + –––––––––ენ/იან | **გა**აკეთებენ   |

| Translation | Infinitive | Present   | Future Simple |
| ----------- | ---------- | --------- | ------------- |
| To conduct  | ჩატარება   | ვატარებ   | ჩავატარებ     |
| To do       | გაკეთება   | ვაკეთებ   | გავაკეთებ     |
| To eat      | შეჭმა/ჭამა | ვჭამ      | შევჭამ        |
| To help     | დახმარება  | ვეხმარები | დავეხმარები   |
| To listen   | მოსმენა    | ვუსმენ    | მოვუსმენ      |
| To prepare  | მომზადება  | ვამზადებ  | მოვამზადებ    |
| To rest     | დასვენება  | ვისვენებ  | დავისვენებ    |

#### Irregular

| Translation | Infinitive | Present | Future Simple |
| ----------- | ---------- | ------- | ------------- |
| To drink    | დალევა     | ვსვამ   | დავლევ        |
| To watch\*  | ყურება     | ვუყურებ | ვუყურებ       |

\*Note! Present and future simple forms of the verb to watch (ყურება) are the same.
